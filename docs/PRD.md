# KingFlow ERP V1.0 产品需求

单企业、多仓库的中小商贸 ERP Demo，PC 浏览器优先，1440/1366 自适应。原创视觉，不使用金蝶商标及专有素材。真实 API、真实数据库、刷新持久化，不假审核、不假成功。

## 模块及范围

工作台（经营概览、我的待办）；基础资料（商品、单级分类、客户、供应商、仓库）；采购（订单、入库、统计）；销售（订单、出库、统计）；库存（余额、流水、调整、预警）；财务（应收、应付、收款、付款、概览）；经营报表（销售、采购、库存、往来）；系统（用户、角色权限、日志、个人设置）。

Phase 0–2：工程、认证、完整导航、个人中心、全部基础资料的新增/详情/编辑/查询/启停/安全删除、商品 CSV。Phase3继续实现采购订单、审核、分批入库、库存与应付真实联动，并开放入库/余额/流水/应付只读查询及来源追溯。其余页面明确开发中；付款留Phase5，经营图表留Phase6。

## 主数据

商品：编码唯一、名称、分类、规格、单位、采购价分、销售价分、整数预警数量、启停、创建/更新时间。客户：唯一编码、名称、联系人、电话、邮箱、地址、备注、启停。供应商同客户（邮箱可选）。仓库：唯一编码、名称、位置、负责人、启停。分类：唯一编码、名称、启停。金额为非负整数分，数量非负整数，名称必填；列表关键词、状态、分类、分页、排序。停用数据不用于新业务；引用数据禁止硬删除。

## 业务不变量

采购草稿→待审核→已审核→部分入库→已入库；销售草稿→待审核→已审核→部分出库→已出库。待审核可驳回为草稿。仅草稿可编辑，前端不能任意改状态。订单行保存商品及价格快照。数量为正整数，金额使用整数分乘数量求和。

入库只对已审核/部分入库订单，累计不可超订购量；同一事务增加库存、流水、应付、累计入库量和订单状态。出库同理，校验本仓库存、条件扣减、生成应收，失败整体回滚。按仓库+商品唯一库存余额，不能负库存。调整需原因、记录操作人和流水。正式过账不可编辑，V1 无冲销。幂等键绑定用户、操作和请求摘要，同键异请求冲突。

财务：实际入库生成应付，实际出库生成应收；支持部分结算，结算>0且≤未结余额，事务+条件更新防超结；关联准确来源，防重复。状态未结清/部分结清/已结清。

统计：销售按正式出库、采购按正式入库；库存用余额，应收付用未结余额；Asia/Shanghai 的日期范围转 UTC 半开区间。报表支持 CSV，BOM、双引号转义、公式注入防护。

## 权限

管理员全部；采购维护商品/分类/供应商并处理采购单；销售维护客户并处理销售单；仓库只读主数据、执行出入库及调整；财务只读主数据、处理往来；访客仅授权查询。后端为权限最终边界。

## V1 排除

生产/BOM/MRP、总账凭证、税务/电子发票、多币种、集团合并、支付接口、审批设计器、采购销售退货、跨仓调拨、多租户计费。不作为直接商用财税系统。

## 验收

每阶段按 WORKFLOW 验证。首轮能安装、迁移、Seed、启动、登录退出、导航，新增及编辑五种主数据，查询启停，刷新仍存在；未登录401、无权限403、非法输入422、重复编码409；Lint/类型/集成/浏览器测试/构建通过。
