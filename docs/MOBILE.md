# 手机端适配说明

2026-10-19按用户最新指令停止扩展交付测试，转为响应式Web适配，不开发独立原生App。

## 使用方式

同一个Web地址自动按屏幕宽度切换：小于992px使用手机/平板布局，992px及以上保留桌面侧栏。手机横屏也可使用侧滑菜单。

- 顶部显示当前页面、功能菜单、搜索及头像菜单；头像中保留个人设置与退出。
- 底部提供工作台、全部功能、消息、我的四个快捷入口；全部功能按现有角色权限显示。
- 基础资料、订单、库存及财务列表在表格区域内左右滑动，不删减业务字段与操作。
- 查询条件纵向排列，手机日期范围使用系统日期输入，避免双月日历超出屏幕。
- 采购/销售订单商品明细、采购入库及销售出库使用卡片式填写，数量、价格、剩余量和金额可直接操作。
- 新增、编辑、查看详情的抽屉在窄屏占满宽度，正文独立滚动，底部操作栏留出安全区；详情、报表和财务卡片按窄屏重排。
- 顶部/底部导航与表单控件扩大触摸区域；支持刘海屏底部安全区和移动键盘布局调整，保留浏览器缩放。
- 为局域网HTTP浏览器提供使用安全随机数的UUID兼容实现，仍复用原API、金额计算、状态与幂等逻辑。

## 本地运行与手机访问

通常在项目目录运行 `pnpm dev`，打开 http://localhost:5173。浏览器开发者工具可切换手机尺寸预览。

实体手机需要与电脑在同一局域网，或访问已经部署的HTTPS站点。手机上的localhost指手机本身，不是电脑。

需要局域网调试时，在第一个终端将来源配置为电脑的实际局域网地址后启动API：

```powershell
$env:NODE_ENV='development'
$env:APP_ORIGIN='http://你的电脑局域网IP:5173'
pnpm --filter @kingflow/api dev
```

第二个终端启动可供手机访问的前端，然后在手机浏览器打开上述来源地址：

```powershell
pnpm --filter @kingflow/web exec vite --host 0.0.0.0 --port 5173
```

这只用于局域网开发；正式发布使用既有HTTPS部署来源，不使用Vite开发服务。来源检查仍保持精确匹配，不能把任意Origin加入白名单。
