# 账号注册与审核

2026-10-19：按用户选择采用公开注册、管理员审核。登录页不展示、也不预填演示账号与密码。保留已有手机适配。

## 使用流程

1. 登录页点击「没有账号？提交注册申请」，或直接访问 `/register`。
2. 填写账号、姓名、密码与确认密码。账号为3–60位字母、数字、下划线或短横线；密码至少12位，包含大小写字母、数字和符号，UTF-8不超过72字节，不包含系统名称。
3. 提交后保存为 `PENDING`，不会自动登录，不会授予业务访问资格。确认申请人身份需要管理员线下核实；当前没有短信或邮件身份验证。
4. 管理员在「系统管理 → 用户管理」筛选「待审核」，点击「审核注册」，选择业务角色并通过，或驳回。
5. 通过后为 `ACTIVE`，用户可使用自己设置的密码登录；驳回为 `REJECTED`，不能登录。已驳回用户名保留，不允许重复申请或直接启用；如需重新开户，管理员核实后通过新增用户创建其他账号。

审核只能授予普通业务角色；额外管理员需由现有管理员通过原有用户管理功能明确创建。申请人不能自行选择角色、提交状态或通过普通编辑接口跳过审核。

## 配置与接口

- `REGISTRATION_ENABLED=true`（默认）：公开注册，管理员审核。
- `REGISTRATION_ENABLED=false`：前端隐藏注册入口，后端拒绝注册请求；管理员仍可直接创建账号。
- `GET /api/v1/auth/options`：返回注册开关与 `registrationMode: approval`。
- `POST /api/v1/auth/register`：仅接受 `{ username, displayName, password }`；201返回账号与待审核状态，不返回密码、哈希或Session。
- `POST /api/v1/system/users/:id/review`：管理员登录、合法Origin及CSRF令牌；请求为 `{ decision: APPROVE, roleId }` 或 `{ decision: REJECT }`。
- 用户列表新增 `PENDING`、`REJECTED` 状态筛选。

注册接口每IP每小时最多10次尝试，包括失败请求；同一企业出口IP下超过此数量可由管理员直接创建账号。公网反向代理必须按部署文档配置真实来源与可信代理。当前限流为单实例内存存储，重启后清零；水平扩容前需替换共享限流存储和数据库。

## 安全约束与上线

- bcrypt 12轮哈希；后台不存储明文密码，审计不记录密码或请求体。
- 公开注册使用严格Origin校验；管理员审核同时使用身份、实时管理员权限与CSRF校验。
- 注册、审核、审计在事务中完成；SQLite写锁串行化审核并重读申请状态，重复审核返回409。
- 待审核及已驳回账号即使密码正确也不能创建Session。对正确凭据显示审核状态，错误凭据返回通用登录错误。
- 用户名唯一约束保护重复提交；注册接口关闭时服务端返回403。
- 首次生产部署使用 `pnpm db:bootstrap` 创建管理员，不能通过公网注册获得首任管理员。该命令拒绝覆盖已有管理员。
- 生产应使用空业务库加迁移与初始化，不运行Demo Seed、不复制开发库或开发 `.env`，不沿用演示账号密码。
- 生产登录接口额外拒绝原演示口令（`DEMO_CREDENTIALS_DISABLED`），避免遗漏修改的演示账号直接用于公网登录；这不替代首次初始化及旧账号密码审查。
