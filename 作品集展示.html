业务与工程，形成闭环

支持实际操作与刷新持久化；审核、过账、库存和结算规则均在后端校验。

采购与销售

采购订单 → 审核 → 分批入库 → 应付 → 付款
销售订单 → 审核 → 分批出库 → 应收 → 收款

商品/客户/供应商/仓库基础资料，库存余额与流水、库存调整和预警，经营图表与 CSV 报表。

重点实现

  • 事务与条件更新，防止负库存和超额结算。
  • 幂等键及唯一来源约束，断网重试不重复过账。
  • 整数分金额与成交价格快照，保持历史一致。
  • 服务端角色授权、Session/CSRF、脱敏审计。

首次运行

准备 Node.js 22.12+ 或 24、pnpm 11.25；在解压后的项目目录打开终端，安装依赖需要网络。

pnpm install --frozen-lockfile
pnpm db:migrate
pnpm db:seed
pnpm dev

访问 http://localhost:5173
演示账号 admin / KingFlow@2026

此离线页面只展示项目资料；真实业务操作需启动前后端。

建议现场演示

  1. 新商品采购 10 件 × 80 元，分批入库 6+4 件。
  2. 同仓销售出库 3 件 × 120 元，库存剩 7 件。
  3. 应收 360 元，分两次收 100+260 元，完成结清。
  4. 查看流水、报表、审计，并验证库存不足与越权被拒绝。

完整演示指南 · 安装说明 · API · 数据库

项目范围：本地/受控环境的单企业商贸 ERP Demo；SQLite 与报表内存聚合面向演示规模。未包含银行支付、会计总账、税务、生产制造、退货与跨仓调拨。不宣称商业上线或生产业务指标。源码、迁移、Seed 与测试完整提供；使用 Codex 辅助开发。
